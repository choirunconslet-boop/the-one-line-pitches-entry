# The One-Line Pitches Entry

Entry for the make.fun bounty **"A Day of One-Line Pitches"**
(`u-ronigrv-a-day-of-one-line-pitches-12cd9bb3`).

`main.py` writes one sentence to `/output/entry.txt` — a plain,
friendly pitch that would convince a friend who has never coded to
let an AI agent build their first app idea on make.fun.

The pitch (160 characters, one line):

> Tell an AI agent your app idea in plain words and it'll build the first version for you — no coding, no cost to try, and you can change anything you don't like.
